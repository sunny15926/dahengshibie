# 传统装甲板视觉识别流程说明

## 概述

本系统采用传统视觉方法，不依赖深度学习模型，仅利用装甲板两侧发光灯条的颜色特征与几何特征完成目标识别。整体识别按「图像预处理 → 颜色通道筛选 → 形态学处理 → 轮廓查找与灯条过滤 → 灯条匹配配对 → 装甲板判定」的流水线进行，最终输出装甲板的中心点坐标与四个角点坐标，作为后续自瞄解算的输入。

## 一、图像预处理

系统首先将相机采集的 BGR 图像转换到 HSV 颜色空间，使颜色信息以**色相（H）**、**饱和度（S）**、**明度（V）**三个相互独立的通道表达。这一转换的目的是将目标的颜色属性与亮度属性分离，从而使后续的颜色分割对光照变化、阴影和整体亮度波动具有更强的鲁棒性，为逐像素的颜色判定提供稳定的特征空间。

## 二、颜色通道筛选（颜色阈值分割）

在 HSV 空间内，依据设定的敌方颜色（红或蓝）对图像逐像素进行阈值二值化，仅保留属于目标颜色的像素，得到一幅二值图——灯条区域为前景（白色），其余背景（黑色）。具体规则如下：

- **色相（H）区间**：仅保留敌方颜色的色相范围。其中红色在色相环上跨越 0°/180° 两端，因此需用两段区间取并集（如 H∈[0,20]∪[160,180]）；蓝色色相集中，仅用一段区间（如 H∈[100,124]）。
- **饱和度（S）下限**：用于排除白色、灰色等低饱和度的非目标物体，保证保留区域具有足够鲜明的颜色。
- **明度（V）下限**：保证保留区域具有较高亮度，契合装甲发光灯条「高亮度」的显著特征；同时通过明度上限抑制过曝区域带来的干扰。

此步骤的目的是利用灯条**高亮度、高饱和**的颜色特征，在复杂背景中快速、稳定地提取出候选灯条区域，将识别问题从灰度/颜色空间的全局搜索简化为对二值前景区域的几何处理。

## 三、形态学处理

对二值图执行闭运算（先膨胀后腐蚀，采用小尺寸矩形结构元素）。其目的是填补灯条内部因过曝或遮挡产生的细小空洞、连接由噪声造成的细小断裂，使灯条连通域更加完整，同时在一定程度上抑制孤立的散点噪声，为后续轮廓提取提供更干净、连续的前景区域。

## 四、轮廓查找与灯条过滤

### （1）轮廓查找

对二值图提取最外层轮廓（只取外边界，因灯条为实心亮块），并保留全部边界点以保证拟合精度。随后对每一段轮廓求取最小外接旋转矩形，据此计算灯条的各项几何属性，包括：中心点、上下端点、朝向角、长度、宽度及长宽比。

此步骤的目的是将像素级的连通域转换为带有明确几何参数的矩形表示，从而为后续的几何筛选和配对判定提供量化依据。

### （2）灯条几何筛选

装甲发光灯条具有「**长条矩形、高亮度**」的典型形态特征。为排除杂光、反光及其他非灯条目标，系统通过以下几何条件对候选灯条进行过滤：

- **倾斜角度**：灯条应接近竖直方向，其朝向偏离竖直方向的角度须小于设定阈值（约 45°），用于剔除明显倾斜的干扰区域。
- **长宽比**：灯条应呈细长条状，其长宽比须落在合理区间（约 1.5～20），用于剔除近似方形或过扁的杂块。
- **长度（面积下限）**：灯条的最小外接矩形长边须大于最小长度阈值（约 8 像素），用于排除面积过小的噪声点。

只有同时满足上述三个条件的轮廓才被认定为有效灯条，并按中心横坐标从左到右排序，便于后续两两配对。

## 五、灯条匹配配对

将筛选出的灯条两两组合，逐一判断其是否能构成一块装甲板。一对灯条须同时满足以下三条配对规则：

- **平行性（相互平行且与连线垂直）**：两灯条方向应近似一致，且均与两灯条中心连线近似垂直，从而构成矩形。以两灯条与中心连线的垂直误差衡量，取左右两侧误差的较大值，须小于设定阈值（约 25°）。
- **高度相近**：左右两根灯条的长度应基本一致，二者长度比（长灯条/短灯条）须小于设定阈值（约 1.5），避免出现一侧明显过短的畸形组合。
- **间距合理**：两灯条中心间距与灯条长度的比值（即装甲板宽高比）须落在合理区间（约 1～5），保证两灯条既不过近也不过远，符合装甲板的实际宽高比例。

## 六、装甲板判定与去重

只有同时满足上述全部几何条件的灯条对，才被最终判定为一块有效装甲板。此外，当一根灯条同时参与多组候选配对（即一根灯条被配给多个目标）时，系统仅保留几何误差最小、最接近标准矩形的配对，其余候选予以剔除，从而避免同一灯条被重复计入多个目标，保证识别结果的一致性与唯一性。

## 七、结果输出

对于每一块识别出的装甲板，系统输出两类坐标信息：

- **中心点坐标**：取左右两灯条中心连线的中点，作为装甲板的参考中心。
- **四个角点坐标**：依次取左灯条上端点、右灯条上端点、右灯条下端点、左灯条下端点，构成装甲板的四个顶点（左上、右上、右下、左下），完整描述装甲板的位置与姿态轮廓。

上述中心点与四个角点坐标即为后续自瞄解算的输入，用于估计目标的空间位姿、计算瞄准点并完成弹道补偿。
